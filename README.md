# منصة نهج الأوائل (Nahg Al-Awael Platform) - Android App

تطبيق أندرويد متكامل لمنصة نهج الأوائل للفصول الدراسية الإلكترونية والاختبارات التفاعلية للطلاب والمعلمين.

## المميزات الرئيسية
- **بوابة الطلاب**: دخول فوري لأداء الاختبارات عبر الرمز المكون من 6 أرقام مع دعم التوقيت التنازلي، الترتيب العشوائي للأسئلة والخيارات، وقفل الأمان.
- **الفصول التفاعلية**: الانضمام للفصول الدراسية برمز الفصل ومتابعة الواجبات، الشروحات، روابط البث والاجتماعات، والاختبارات المخصصة.
- **بوابة ولوحة تحكم المعلم**: إنشاء وتعديل ونشر الاختبارات، إدارة بنك الأسئلة، واستعراض سجلات النتائج ولوحة الشرف للطلاب المتفوقين.
- **مراجعة الإجابات والتصحيح التلقائي**: عرض تفصيلي لدرجات الطالب وتوضيح الإجابات النموذجية.

## البنية التقنية
- **اللغة**: Kotlin
- **واجهة المستخدم**: Jetpack Compose & Material Design 3
- **إدارة الحزم**: Gradle Version Catalog (libs.versions.toml)
